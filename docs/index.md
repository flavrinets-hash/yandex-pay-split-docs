# Яндекс Пэй и Сплит: документация для партнёра

Документация для команды интернет-магазина, которая подключает оплату через Яндекс Пэй и Яндекс Сплит, и для инженера поддержки, который помогает партнёрам с интеграцией.

!!! note "Неофициальная документация"
    Материалы написаны по публичной [документации Яндекс Пэй](https://pay.yandex.ru/docs/ru/) и проверены в тестовой среде (Sandbox). Проект не связан с Яндексом. Ключи и идентификаторы в примерах заменены плейсхолдерами вида `<MERCHANT_ID>`.

## Основные понятия

Мерчант
:   Магазин, который принимает оплату через Яндекс Пэй. У мерчанта есть идентификатор `merchantId` и API-ключ.

Заказ (order)
:   Платёжная сессия, созданная методом `POST /v1/orders`. У заказа есть статус оплаты `paymentStatus`.

Операция (operation)
:   Действие над заказом: списание, возврат, отмена. У операции есть свой тип `operationType` и свой статус `status`. Подробнее в разделе [Статусы](reference/statuses.md).

Callback URL
:   Адрес на бэкенде магазина, на который Яндекс Пэй отправляет вебхуки. Путь `/v1/webhook` Яндекс Пэй добавляет к нему сам.

Вебхук
:   POST-запрос от Яндекс Пэй о смене статуса заказа или операции. Тело запроса — JWT-токен, подписанный алгоритмом ES256.
